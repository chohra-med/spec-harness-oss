# Method: Grill Me

Portable adaptation of Malik Chohra's Grill Me method, dated 2026-10-05. Investigate before asking.

1. Read applicable project rules and inspect the actual source, rendered artifact or runtime configuration that can establish the claim. Treat inventories and prior summaries as leads.
2. Compare the artifacts and rules. Rank evidenced contradictions by impact and cite exact paths/lines. Fix mechanical mismatches within the authorized scope.
3. Ask only unresolved choices whose answers materially change behavior, identity or scope. State a recommendation and what evidence would change it. Ask at most four focused questions through the available client. Do not ask what source inspection can answer.
4. If no material ambiguity remains, proceed without manufacturing questions. Record unresolved choices as PENDING and preserve the affected output until resolved.

This portable method does not prescribe private project files or broaden the caller's write authority.
