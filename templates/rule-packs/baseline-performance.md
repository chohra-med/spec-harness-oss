- **PERF-01** Measure a performance problem with a profiler or lab tool before changing code for it, and measure again afterwards. (source: web.dev, Web Vitals, https://web.dev/web-vitals/)
- **PERF-02** Check performance on a production build with realistic devices and networks, not only in development mode. (source: web.dev, Web Vitals, https://web.dev/web-vitals/)
- **PERF-03** Add caching or memoization only for a measured hot path, because it is a performance hint and not a guarantee. (source: React documentation, memo, https://react.dev/reference/react/memo)
