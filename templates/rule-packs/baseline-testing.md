# Baseline pack: testing

<!-- rule-layer: baseline -->
<!-- pack: baseline-testing -->

- **TEST-01** Add or update a test for every behaviour change, in the same change. (source: Software Engineering at Google, chapter 12 Unit Testing, https://www.oreilly.com/library/view/software-engineering-at/9781492082781/ch12.html)
- **TEST-02** Test through the public interface and observable behaviour, not private implementation details. (source: Software Engineering at Google, chapter 12 Unit Testing, https://www.oreilly.com/library/view/software-engineering-at/9781492082781/ch12.html)
- **TEST-03** Give each test one behaviour to check and a name that says which behaviour it is. (source: Software Engineering at Google, chapter 12 Unit Testing, https://www.oreilly.com/library/view/software-engineering-at/9781492082781/ch12.html)
- **TEST-04** Prefer real objects or fakes over mocks when they are fast and deterministic. (source: Software Engineering at Google, chapter 12 Unit Testing, https://www.oreilly.com/library/view/software-engineering-at/9781492082781/ch12.html)
- **TEST-05** Keep tests deterministic, with no uncontrolled network, clock or random input. (source: Software Engineering at Google, chapter 12 Unit Testing, https://www.oreilly.com/library/view/software-engineering-at/9781492082781/ch12.html)
