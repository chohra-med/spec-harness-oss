# Tool pack: Expo Router

<!-- rule-layer: tool -->
<!-- pack: tool-expo-router -->
<!-- applies: expo-router >=3 -->

- **ROUTER-01** Define each navigator in the `_layout` file of the directory whose screens it wraps. (source: Expo documentation, Navigation layouts, https://docs.expo.dev/router/basics/navigation-layouts/)
- **ROUTER-02** Put app-wide providers and startup work in the root layout, not in individual screens. (source: Expo documentation, Navigation layouts, https://docs.expo.dev/router/basics/navigation-layouts/)
- **ROUTER-03** Use a route group folder in parentheses to share a layout without adding a URL segment. (source: Expo documentation, Layout routes, https://docs.expo.dev/router/layouts/)
