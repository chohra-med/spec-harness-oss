# Baseline pack: clean code

<!-- rule-layer: baseline -->
<!-- pack: baseline-clean-code -->

- **CLEAN-01** Keep each change to one purpose and split unrelated edits into separate changes. (source: Google Engineering Practices, code review guide, https://google.github.io/eng-practices/review/)
- **CLEAN-02** Choose the simplest design that meets the current requirement and do not build for needs that do not exist yet. (source: Google Engineering Practices, code review guide, https://google.github.io/eng-practices/review/)
- **CLEAN-03** Name functions, variables and files so that a reader understands what they do without a comment. (source: Google Engineering Practices, code review guide, https://google.github.io/eng-practices/review/)
- **CLEAN-04** Write comments that explain why the code exists, not what it does. (source: Google Engineering Practices, code review guide, https://google.github.io/eng-practices/review/)
- **CLEAN-05** Follow the project's existing style and patterns before introducing a new one. (source: Google Engineering Practices, code review guide, https://google.github.io/eng-practices/review/)
